# مذكرة الرياضيات – الصف العاشر (مدرسة راشد بن سعيد ح3)

## النشر
1. ارفع محتويات هذا المجلد كما هي إلى مستودع GitHub (index.html و netlify/ و package.json و netlify.toml).
2. في Netlify: Add new site → Import from Git → اختر المستودع → Deploy.
3. كلمة مرور المعلم الافتراضية: 4321 (لتغييرها أضف متغير البيئة TEACHER_PASSWORD ثم أعد النشر).

## مهم للنشر
- يجب النشر عبر GitHub (Import from Git) وليس بالسحب والإفلات، لأن الخادم (Functions) يحتاج تثبيت الحزم تلقائياً.
- إن كنت قد أضفت متغير TEACHER_PASSWORD سابقاً فكلمة المرور هي قيمته، وإلا فهي 4321. احذف المتغير لتعود إلى 4321.
- بعد أي تغيير في المتغيرات: Deploys ثم Trigger deploy ثم Clear cache and deploy site.

## الاستخدام
- تبويب «المعلم» ← أدخل كلمة المرور ← أضف الطلاب يدوياً أو استورد ملف Excel (الأسماء في العمود الأول، والصف الأول قد يكون عنوان «الاسم»).
- لا يدخل الطالب إلا إذا كان اسمه مضافاً. يكتب الطالب اسمه كما سجّلته (لا يهم اختلاف الهمزات أو التشكيل أو المسافات الزائدة).
- جدول الطلاب يعرض مرات الدخول والدروس المنجزة والمتوسط والنتائج لكل طالب.

## ميزات الإصدار الحالي
- تبويب «المعلم: الأستاذ إسماعيل» محمي بكلمة المرور ويختفي بعد دخول أي طالب.
- 3 نماذج اختبار لكل وحدة (أساسي/متوسط/متقدم) بألوان مختلفة، تُفتح بعد إنهاء جميع دروس الوحدة، ولكل طالب محاولة واحدة.
- أثناء الاختبار: منع النسخ واللصق وتحديد النص، مؤقّت 10 دقائق، تسجيل مغادرة الصفحة (3 مخالفات = إنهاء تلقائي) وإبلاغ المعلم. هذه إجراءات للحد من الاستعانة بأدوات خارجية ولا تمنعها تماماً (مثل تصوير الشاشة بجهاز آخر).
- تصدير جداول المعلم إلى Excel (3 أوراق) أو PDF (زر الطباعة ثم «حفظ كـ PDF»).
